🐾 Pet Shop

Pet Shop is an interactive front-end application built with HTML, CSS, and JavaScript for fun and learning. When the user presses the arrow, a new animal appears, and the application automatically reads a description of the animal with voice, making the experience more lively and enjoyable.

✨ Main features

🐶 Interactive animal display

🔊 Automatic voice-over for animal description

🎨 Simple and clean design for a pleasant user experience

🛠️ Technologies used

HTML5, CSS3, JavaScript (ES6)

🎯 Project goal

This project is built for fun and practice front-end, demonstrating skills in interactivity and animation with JavaScript.
